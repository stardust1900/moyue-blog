
> 初版把范围锁死在"传统贯口活"，造成两类遗漏：一是**1949 年后的新相声里同样有大量贯口**，且难度往往更高；二是**若干名录里列了名、但初版只写"存目"的段子**，其实有可考文本或有确切考据结论。本卷一并补齐。

## 一、现代相声中的贯口

一个常见误解是"只有《八扇屏》《地理图》才叫贯口"。贯口是一种**表演形式**，不是一份固定剧目表。新相声里的贯口不止存在，而且因为词是现代名词（药名、舞名、职务名），没有传统辙口可借力，背诵难度更大。这类作品多仍有版权，故此处只录**贯口段落本身的完整文本**，不录整段相声，并标明出处。

### 1. 常宝霆、王佩元《挖宝》（1972）

常宝霆、朱学颖创作，1972 年首演，1973 年国庆天津电视台播出，是相声恢复期第一部新作品。底段由**捧哏**王佩元一气罗列七十余种脏器制药药名，是公认比《报菜名》更难的贯口。

**甲（逗哏）起头式（脏器制药贯口，前半）**

```
甲　既然这样的话，那我说说你听听。
乙　行。
甲　脏器制药，已经制造出来的药有……哎，你可数着。
乙　准备好啦。
甲　有用猪胰做的胰岛素。
乙　一种。
甲　有用猪苦胆做的抗菌剂。
乙　两种。
甲　有肝精注射液、血管舒张素、复方动脉粉、糖衣胎盘片。
乙　六种。
甲　健骨片、催乳片、多酶片、钙片、甲状腺片。
乙　十一种。
甲　胸腺粉、乳腺粉、血清粉、脾脏粉、肺粉、肝浸膏粉、后叶止血粉。
乙　十八种啦。
```

**底段药名连诵（通行记录本）**

```
糜蛋白酶、胰蛋白酶、胃蛋白酶、胰酶、胃酶、弹性酶、透明质酸酶、
中性蛋白酶、胆酶、核酶、肝素钠、胆膏、肝素、后叶针、
胆固醇、脑磷脂、血原质、组织胺……
```

> 说明：底段共七十余味药名，各演出本与电台录音略有增删，网络流传的记录稿多只存前二十余味。上列段落为可考文字，其余需据 1973 年录音补齐；此处不以推测填充。

### 2. 姜昆、唐杰忠《着急》

"老急"跟自由市场卖菜的争五分钱，卖菜的一段合辙押韵的诉苦贯口，全用生活口语，是"生活化贯口"的范例。

```
您要省您从大处省，省个十顷带八顷；
要算您从大头算，算个十万带八万；
要算您别跟我算，我穷得都快要了饭，
成天在这儿卖葱蒜，一身泥来一身汗，
刮风下雨也得干，要不然我就甭吃饭，
少给五分我不干，你看合算不合算。
来吧，掏钱，掏钱，五分！
```

### 3. 杨议、杨进明《如此办学》

套用《大保镖》的句式，把兵刃名换成舞名，是"旧贯口填新词"的典型：

```
送鼓舞、彩鼓舞、恒鼓舞、童鼓舞、手鼓舞、长鼓舞、太平鼓舞、
面具舞、祭祀舞、宫廷舞、霍拉舞、拉鼓舞、秧歌舞、红绸子舞、
水袖舞、草帽舞、狮子舞、顶龙舞、盾牌舞、旱船舞、龙升舞、
鞍带舞、倘格舞、伦巴舞、恰恰舞、多榔舞、芭蕾舞……
```

### 4. 群口相声《百将图》

2022 年"八一军旗红"曲艺专场（沈阳）由张学京等演出，用贯口一口气报出一百多位功勋将领姓名，是当代新编的"百名类"贯口。属新创节目，未见公开全本，此处存目。

### 5. 其它现代贯口（存目）

- 各团体《报菜名》新编本：在"满汉全席"后增补现代菜名、洋菜名，词随演员而异。
- 德云社《八扇屏》演出本：在传统各"扇"之外增减少数番，并常以"群八扇"（三人以上分扇）形式演出。
- 新相声中类似的生活化贯口数量不少，因多属有版权作品、且无公开整理本，本套不逐段臆录。

## 二、初版"存目"的考据更正

初版 《戏迷药方及其他》把下面几段一律写成"罕见/失传边缘"，其中两条是明确的错误：

| 段子 | 初版说法 | 核实结论 |
|---|---|---|
| **富贵图** | "罕见段子，存目待考" | **错**。《富贵图》就是《夸住宅》的别名，又名《钟表铺搬家》，相声第三代传人恩绪所创。郭德纲、张文顺及郭德纲、于谦的《富贵图》演出本即由此派生（"你爸爸戴表""钟表铺搬家"等哏）。文本见 《夸住宅》、《贯口活异本 · 住宅 / 器物 / 文武》。 |
| **暗八扇** | "群口形式的《八扇屏》，文本与《八扇屏》同" | **不准确**。《暗八扇》是独立的对口贯口活，《中国传统相声大全》第一本收有全文，与《八扇屏》并非同一文本。**完整原文已补入 《八扇屏系列异本（暗八扇 · 外八扇 · 梁子 · 入话）》**；另有《外八扇》一并收入。 |
| **卖宝贝** | "与《卖五器》同类，今罕有全本记录" | 基本属实但有补充。确为传统节目、德云社与潘云侠/史爱东等有演出录像，坊间可见片段（如"搁家里能避邪，搁身上能防身……"），但**未见可靠的全本记录稿**，本套仍只存目，不强凑文本。 |
| **百将图** | 列入"唱词贯口"却未给文本 | 传统名录中的《百将图》与新编群口同名异实；两者均无公开全本，存目。 |
| **戏迷药方** | "网络无可靠完整记录本，只收说明" | **可以补齐**。《中国传统相声大全》第三本收有《戏迷药方》全文，**完整原文已补入 《贯口活异本 · 住宅 / 器物 / 文武》**。 |

> 结论：初版所谓"基本收全"站不住脚。把"名录里列了名"当成"已收录"，又把"未见于网络搜索"当成"失传"，是两次判断失误。本卷与 《八扇屏系列异本（暗八扇 · 外八扇 · 梁子 · 入话）》、《贯口活异本 · 住宅 / 器物 / 文武》已逐条更正。

## 三、《竹城水寨》另一路流传本（补 《竹城水寨》）

《竹城水寨》已收《竹城水寨》整理本。下列为网络流传的"梁山机关布置"路演出本（约两千字），文字与整理本互有出入，且末尾带"你爸爸出殡/寿日""厨子"的包袱，可见此段实际是从《夸住宅》类的"夸庄园"趟子演化出来的。两本并存，供校勘。

```
老爷子确实了不起啊，自己趁一个大庄园，庄园二三百里，里面的人那是不计其数啊，我听去过那个庄园的人说呀，他说三面靠水一面靠山，山脚下有水寨竹城，竹城上有庄兵把守，竹城下有拦江锁、绞刀、绝户网，如若有人进城，必须先要通知守城人，他去的时候坐着一只小船，船上的人拿起一张弓，搭上一只包头响箭，"日～吧"一声射进竹城，只听得竹城以内仓啷啷一阵铜锣响亮，吱溜溜水寨竹门开放，来了大队的人马，真乃是号炮一声震九霄，大队人马似海潮，将如太行下山虎，马似北海出水蛟，刀枪密布如麦穗，旌旗烈烈空中飘。

一龙旗朱莺双堕，二凤旗五彩缭绕，
三虎旗虎张血口，四豹旗豹爪如刀，
五子旗其有贵子，六顺旗随风飘摇，
七星旗斗放异彩，八卦旗喝倒英豪，
九宫旗金光闪耀，十面旗令人心毛，
数不清兵多少来将多少，一杆大旗飘在空。

一队兵一排枪威风凛凛，二队兵二队锋神鬼皆惊，
三队兵三股叉叉排日月，四队兵四支锏锏放光明，
五队兵五节鞭鞭打上天，六队兵六花棒棒打天灵，
七队兵七星剑吹毛利刃，八队兵八卦刀刀呈鸿鹰，
九队兵九对锁锁人绊马，十队兵十列弓弓上雕翎。

由里面划出四十八只彩篷船，每条船上各有庄丁四名水手四名，当中撑出一只虎头舟，在船首站立一人，此人身高丈余膀大腰圆，面如蟹盖扫帚眉，大环眼高鼻梁翻鼻孔，血盆大口，一部黄焦焦的钢髯，眉宇正中有一颗朱砂大痣，好一似观音如来下临凡间，一脸的水锈，头戴绛紫色扎巾帽，身穿紫缎子箭袖袍，黄绒绳十字袢，胸前交搭十字扣儿，腰系鹅黄色丝鸾带，下身穿粉绫色的兜裆裤，足踏一双薄底儿战靴，外罩一件青缎子英雄氅，上绣狮子滚绣球，鹅黄缎子里儿，怀抱一对儿锯齿飞镰刀，抱拳拱手，这位英雄迎接他上了大船，一声令下但见庄兵们撑篙的撑篙、划船的划船，船行如梭，不多时便进入了水寨竹城，来到山坡儿弃舟上岸，往前走一箭之地便到了头道庄门。

但见门外有四十名庄兵把守，举刀都是清一色的花布蒙头，上身穿紫花布靠袄身扎腰包，下身穿紫花布裤子花裹腿，脚下穿斑尖靸鞋，各抱双手带，燕白翅的队伍分两旁站立，当中为首一人那真是与众不同：这个人身高五尺开外，不足六尺是个五短的身材。只见他面如银盆，说白不白不白又白，白中透亮亮中透白，两条斗鸡眉能紧能松，一对三角眼半闭半睁，两双扇风耳能听千里之遥，一副薄片嘴能够倒背三国，头戴一顶马尾透风巾，顶门中欠茨菰叶，鬓边斜插一朵蓝绒球，未曾行动他先突突地乱跳，青缎的裤子青缎的靠袄，腰系一巴掌宽皮锦带，足踏一双薄底儿战靴，外罩一件青缎的英雄氅，上绣百蝶穿花，每当轻风吹过，外罩随风飘荡，百蝶如飞似舞活灵活现，真假难辨！

怀抱短刀一把抱拳拱手，这位英雄迎接他进了头道庄门，来到二道庄门，但见门外也有四十名庄兵把守，具都是一色青的打扮，头戴青布庄丁帽，青布丝裤子青布丝靠袄，腰系一巴掌宽皮锦带，足踏一双薄底儿兜跟展腰快靴，左手持弓右手拿剑分两旁站立，当中也有一人为首，这个人生得好看，身高九尺策马蜂腰展力膀，面如敷粉唇齿涂朱，额下无须正在少年，两道剑眉直插入鬓，一双俊眼皂白分明，头戴粉绫的六瓣壮丁帽，鬓边斜插一支守正戒银花乐，上身穿粉绫色的紧身靠袄，雪白色的战裙，黄绒绳十字袢，胸前交搭十字扣儿，腰系鹅黄色丝鸾带，下身穿粉绫色的兜裆裤，足下登一双薄底儿战靴，外罩一件粉绫的英雄氅，上绣三蓝牡丹花，左肋下斜挂镖囊，内装十二支亮银镖，金闪闪光亮亮，犹如十二条飞龙藏身，手中倒持五股亮银叉，这位英雄抱拳拱手，迎接他进了二道庄门。

来到天井院一看是三合土的院子，两边刀枪架枪放尽了十八般兵刃，有刀枪剑戟、斧钺钩叉、鞭锏锤抓、镗棍槊棒、拐子流星，上三门下五门，带尖的带刺的带棱的带刃的，带绒绳的带锁链的，带倒齿钩的带峨嵋刺的，十八般兵器是样样俱全。

庭院中一杆大旗高耸入云，锦黄色的门旗随风飘荡，哗哗作响，一共有五间待客厅，进厅一看那真是与众不同，有三十六把金交椅，七十二条银板凳，他去的那一天，正赶上一个好日子——（什么日子？）你爸爸出殡呵这热闹……（去去去，我爸爸出殡是好日子？）不不，不是，那应该是？（我爸爸寿日啊）对，您父亲过寿日，亲朋好友纷纷前来道贺，少说也得有一百多位，那真是高的高、矮的矮、胖的胖、瘦的瘦、丑的丑、俊的俊，穿白的白似雪，穿黑的黑似铁，穿灰的灰似蟹，穿红的红似血，你父亲往外一走，那真是人才出众仪表非凡，头戴冲天冠双插雉尾，一对狐狸尾左右交错，甩搭于背后，身穿赭黄袍，腰横玉带足登朝靴，五缕长髯飘洒胸前，怀令旗令箭指挥千军万马，意在锦绣河山。（这是我爸爸？）这是宋江。（说宋江干嘛，说我爸爸啊）要说你父亲的身份地位，要比宋江高，甭说长相，单说他随身带的这几样兵刃，就足以令人胆战心寒——带什么？有菜刀片刀大砍刀，马勺漏勺大铁勺，火钩火绳烧火棍，匾子油锤大中条，铁线木织顶门杆，镐刀木棍小铡刀。（这是我爸爸？）这是厨子这是。（去你的吧！）
```
